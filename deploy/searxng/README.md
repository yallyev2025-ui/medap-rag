# SearXNG на Timeweb App Platform

Поиск в боте работает через свой метапоиск SearXNG: без ключей Яндекса и без
оплаты. Основной бот собирается из корневого `Dockerfile`, а SearXNG — это
**второе приложение** в той же панели Timeweb.

## 1. Создать приложение SearXNG

В Timeweb App Platform:

1. **Создать** → выберите этот же репозиторий `medap-rag`.
2. Тип сборки — **Docker**.
3. **Путь до директории проекта** — `deploy/searxng` (там лежит свой
   `Dockerfile`).
4. Порт — `8080`.
5. Регион — тот же, где бот (лучше в одной приватной сети).
6. Выложить. Дождитесь статуса «Работает».

Проверка снаружи:

```bash
curl -fsS "https://<адрес-приложения>/healthz"
```

Должно ответить `OK`.

## 2. Прописать адрес в боте

В настройках основного приложения (MedAP Student AI) добавьте переменную:

```env
SEARXNG_URL=https://<адрес-приложения>
```

Если оба приложения в одной приватной сети Timeweb, можно использовать
внутренний адрес — он быстрее и не выходит в интернет.

После сохранения переменной перезапустите бота.

## 3. Проверить поиск

В боте откройте вопрос и выберите источник **«Интернет»**. В ответе должны
появиться ссылки на страницы. Если бот отвечает «Поиск по интернету сейчас не
настроен» — переменная `SEARXNG_URL` не подхватилась или приложение SearXNG
не запустилось.

## Почему не внутри контейнера бота

Можно было бы запускать SearXNG вторым процессом в том же контейнере, но это
утяжеляет и без того большой образ с моделями и усложняет запуск. Отдельное
приложение обновляется независимо и не может уронить бота.

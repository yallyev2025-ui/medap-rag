# Quick Outline — присланное ТЗ (сохранено как получено)

Сохранено «как получено» от владельца продукта — как и `TZ_ADDENDUM.md`, при расхождениях с этим
файлом приоритет у оригинального текста ниже, не у пересказа своими словами.

**Важно (уточнено владельцем продукта после первой, неверной версии этой шапки — не путать!):**

- Quick Outline — это **Level 1** учебного контента (Quick Outline → Core Explanation → Deep
  Material) и генерируется **AI по загруженным учебникам** (не вводится человеком руками — первая
  версия этой шапки утверждала обратное, это было ошибкой).
- Quick Outline **никак не относится к студенческому Q&A**: обычный вопрос студента боту/сайту даёт
  обычный ответ, как сейчас, без Quick Outline. Это инструмент владельца продукта для подготовки
  контента: он вызывает наш API с темой, получает готовую схему, сам её просматривает и выкладывает
  на свой образовательный сайт (отдельный проект, не этот репозиторий).
- Реализация в этом репозитории — **только эндпоинт `POST /v1/quick-outline/generate`**
  (`app/api/v1.py`, `app/workflows/quick_outline.py`), без хранения на нашей стороне: сайт владельца
  сам вызывает этот эндпоинт и сохраняет/показывает результат у себя. Полноценный конвейер Content
  Studio (Draft → Human Review → Publish) в этот репозиторий не входит.
- Quick Outline — это **НЕ** то же самое, что `MODE_INSTRUCTIONS["conspect"]` в `rag/generator.py`
  (детектируется `CONSPECT_PATTERN` по словам «конспект», «кратко разбери» и т.п. в вопросе студента
  и превращает ответ в обычный текстовый конспект-суммари). Quick Outline — строго типизированная
  схема (mechanism / classification / sequence / comparison / definition / cause_effect / process /
  pharmacology / physiology / pathophysiology / anatomy), обязательно пригодная для переноса в
  тетрадь от руки, с `requiredPoints` как отдельным от самой схемы полем и жёстким запретом
  «упрощать до потери смысла». Эту путаницу явно просил не допускать владелец продукта — это два
  разных требования/механизма.

## ТЗ: Quick Outline — «Схема для тетради»

### 1. Что такое Quick Outline

Quick Outline — это первый и самый короткий уровень учебного материала по конкретному учебному вопросу.

Его задача — не заменить объяснение, а дать студенту каркас знания, который можно быстро прочитать, закрыть и попытаться восстановить самостоятельно.

Quick Outline должен отвечать на вопрос:

«Если мне нужно за 1–3 минуты понять структуру этого вопроса и потом рассказать его самому, что должно остаться перед глазами?»

Это не обычный summary, не сокращённая статья и не пересказ большого текста.

### 2. Главная учебная механика

Quick Outline является первым этапом алгоритма:

Увидел → восстановил → понял → рассказал → исправил → повторил.

Поэтому схема должна быть построена так, чтобы студент мог:

1. быстро посмотреть структуру;
2. закрыть/скрыть материал;
3. восстановить содержание по памяти;
4. сравнить с эталоном;
5. увидеть пробелы;
6. перейти к объяснению только тех частей, которые не смог восстановить.

### 3. Что должно находиться внутри Quick Outline

В зависимости от темы схема должна использовать подходящие элементы:

**Определение**

```
Гипоксия
↓
состояние недостаточного обеспечения тканей O₂
```

**Причина → механизм → результат**

```
↓ ↓ ↓
Недостаток O₂
→ нарушение окислительного фосфорилирования
→ ↓ ATP
→ нарушение работы клеточных насосов
→ повреждение клетки
```

**Классификация**

```
Гипоксия
├─ Экзогенная
├─ Респираторная
├─ Циркуляторная
├─ Гемическая
└─ Тканевая
```

**Последовательность**

```
Возбуждение
→ открытие Na⁺-каналов
→ вход Na⁺
→ деполяризация
→ открытие K⁺-каналов
→ выход K⁺
→ реполяризация
```

**Сравнение**

```
Артериальная кровь
O₂ ↑
CO₂ ↓
Венозная кровь
O₂ ↓
CO₂ ↑
```

**Причина → следствие**

```
↓ альвеолярной вентиляции
→ ↑ CO₂
→ ↓ pH
→ респираторный ацидоз
```

**Ключевые термины**

В конце или внутри схемы можно выделять несколько терминов, которые студент обязан помнить.

### 4. Правило компактности

Quick Outline не должен превращаться в лекцию.

Ориентир:

- обычно 1–3 минуты чтения;
- короткие фразы;
- минимум сплошного текста;
- максимум структуры;
- длинные предложения не использовать без необходимости;
- не повторять одно и то же разными словами.

**Плохо**

Симпатическая нервная система оказывает влияние на сердечно-сосудистую систему посредством выделения норадреналина, который взаимодействует с β1-адренорецепторами кардиомиоцитов и приводит к увеличению частоты сердечных сокращений и силы сокращения.

**Хорошо**

```
Симпатика
↓
норадреналин
↓
β₁-рецепторы сердца
↓
↑ ЧСС
↑ сила сокращения
↑ сердечный выброс
```

### 5. Важное правило: не упрощать до потери смысла

Компактность не должна уничтожать медицинскую точность.

Если для понимания механизма необходимы:

- причинно-следственная связь;
- последовательность;
- рецептор;
- медиатор;
- фермент;
- орган;
- клеточная структура;
- направление изменения;

они должны остаться в схеме.

Нельзя превращать сложный медицинский механизм в набор слишком общих слов только ради краткости.

### 6. Quick Outline ≠ Core Explanation

В системе должны существовать разные уровни.

**Level 1 — Quick Outline**

Каркас знания.

```
Причина
↓
механизм
↓
изменение
↓
клинический/функциональный результат
```

**Level 2 — Core Explanation**

Полноценное понимание.

Здесь уже объясняется:

- почему происходит процесс;
- как работает механизм;
- что означает каждый этап;
- какие связи нужно понимать;
- что важно сказать на экзамене.

**Level 3 — Deep Material**

Глубокое изучение.

Подробности, исключения, дополнительные механизмы, сложные взаимосвязи, клинические примеры и т. д.

### 7. Quick Outline должен быть пригоден для рукописной записи

Это принципиально.

Студент должен иметь возможность открыть Quick Outline и перенести его в тетрадь, не переписывая несколько страниц текста.

Поэтому предпочтительны:

- стрелки;
- короткие блоки;
- деревья классификации;
- таблицы;
- последовательности;
- ↑ / ↓;
- →;
- + / −;
- короткие определения;
- ключевые термины.

### 8. Quick Outline должен быть структурирован по типу знания

Не нужно использовать одну и ту же структуру для всех медицинских вопросов.

**Если это механизм**

```
Триггер
↓
рецептор
↓
сигнальный путь
↓
эффектор
↓
результат
```

**Если это классификация**

```
Основной объект
├─ Тип 1
│  ├─ признак
│  └─ признак
├─ Тип 2
└─ Тип 3
```

**Если это процесс**

```
Этап 1
↓
Этап 2
↓
Этап 3
↓
Результат
```

**Если это сравнительная тема**

| Признак | A | B |
|---|---|---|
| Причина | … | … |
| Механизм | … | … |
| Результат | … | … |

**Если это фармакология**

```
Препарат
↓
мишень
↓
механизм действия
↓
эффект
↓
показания
↓
важные НЯ
```

**Если это патофизиология**

```
Причина
↓
первичное нарушение
↓
патогенез
↓
вторичные изменения
↓
проявления
```

**Если это физиология**

```
Стимул
↓
рецептор
↓
центр/регулятор
↓
эффектор
↓
ответ
↓
обратная связь
```

### 9. Что нельзя делать

Quick Outline не должен:

- быть просто уменьшенной копией Core Explanation;
- состоять из одного большого абзаца;
- содержать вступления типа «В данной теме мы рассмотрим…»;
- содержать мотивационный текст;
- добавлять информацию, которой нет в утверждённом учебном материале;
- самостоятельно придумывать медицинские факты;
- заменять отсутствующие данные общей информацией из модели;
- перегружаться второстепенными деталями;
- превращаться в набор бессвязных bullet points;
- использовать декоративные элементы, которые не помогают учиться.

### 10. Пример: физиология

Тема: сердечный цикл

**Плохо:**

Сердечный цикл представляет собой совокупность электрических и механических процессов, происходящих в сердце во время одного сердечного сокращения. Он включает систолу и диастолу…

Это просто сокращённый текст.

**Хорошо:**

```
СЕРДЕЧНЫЙ ЦИКЛ
Диастола
↓
наполнение желудочков
Систола предсердий
↓
дополнительное наполнение
Систола желудочков
↓
↑ давление в желудочках
↓
закрытие AV-клапанов
↓
изгнание крови
↓
открытие полулунных клапанов
Расслабление
↓
↓ давление в желудочках
↓
закрытие полулунных клапанов
↓
начало нового наполнения
```

### 11. Пример: патофизиология

Тема: метаболический ацидоз

```
МЕТАБОЛИЧЕСКИЙ АЦИДОЗ
Первичное нарушение
↓
↓ HCO₃⁻
↓
↓ pH крови
Причины
├─ ↑ образование кислот
├─ ↓ выведение H⁺
└─ потеря HCO₃⁻
Компенсация
↓
гипервентиляция
↓
↓ PaCO₂
↓
частичная коррекция pH
Если тяжёлый
↓
нарушение ферментных процессов
↓
↓ сократимость / функции органов
```

### 12. Пример: фармакология

β₁-блокатор

```
β₁-блокатор
β₁-рецепторы
↓
↓ стимуляция аденилатциклазы
↓
↓ cAMP
↓
↓ Ca²⁺ в кардиомиоцитах
Результат
├─ ↓ ЧСС
├─ ↓ сократимость
└─ ↓ сердечный выброс
Основные эффекты
→ снижение АД
→ снижение потребности миокарда в O₂
```

### 13. Пример: анатомия

```
БЕДРЕННЫЙ НЕРВ
Корешки
L2–L4
↓
поясничное сплетение
↓
бедренный нерв
↓
передняя группа мышц бедра
Двигательная функция
→ разгибание голени
Чувствительность
→ передняя поверхность бедра
→ медиальная поверхность голени
```

### 14. Связь с экзаменационным вопросом

Quick Outline должен помогать восстановить ответ на экзаменационный вопрос, а не просто красиво выглядеть.

Поэтому для каждого вопроса система должна по возможности выделять:

```
ЧТО НУЖНО ЗНАТЬ
↓
КЛЮЧЕВЫЕ ПУНКТЫ
↓
МЕХАНИЗМ / ЛОГИКА
↓
ЧТО НУЖНО СКАЗАТЬ
```

При этом requiredPoints и Quick Outline — не одно и то же.

Quick Outline показывает структуру.

Required Points определяет, какие конкретные элементы ответа должны быть покрыты при проверке.

### 15. Формат данных

На уровне контента желательно сохранять Quick Outline отдельно:

```json
{
  "quickOutline": {
    "type": "mechanism",
    "blocks": [
      {
        "title": "Причина",
        "items": ["..."]
      },
      {
        "title": "Механизм",
        "items": ["...", "..."]
      },
      {
        "title": "Результат",
        "items": ["..."]
      }
    ]
  }
}
```

Но структура должна позволять использовать разные типы:

```
mechanism
classification
sequence
comparison
definition
cause_effect
process
pharmacology
physiology
pathophysiology
anatomy
```

Не нужно насильно загонять все темы в один JSON-шаблон, если это ухудшает структуру.

### 16. Критерий готовности

Quick Outline считается качественным, если студент, прочитав его 1–3 минуты, может:

закрыть схему → взять чистый лист → воспроизвести основную структуру вопроса → рассказать ответ своими словами.

Если после закрытия схемы студенту нечего восстановить, схема слишком поверхностная.

Если для её прочтения требуется 10 минут, это уже не Quick Outline.

Главный критерий: не количество текста, а количество полезной структуры, которую студент может восстановить из памяти.

# Фаза 03 — Telegram-бот (aiogram): /start, /help, ответы на вопросы

## Цель
Собрать рабочего Telegram-бота на aiogram 3.x, который принимает любое текстовое сообщение, прогоняет через retriever (фаза 01) + generator (фаза 02) и отвечает студенту. Без лимитов и БД пользователей — это фаза 04.

## Предпосылки
Фазы 01, 02 выполнены и протестированы локально. В `.env` есть `TELEGRAM_BOT_TOKEN`.

## Что создать

### `bot/main.py`
- Инициализация `Bot(token=settings.TELEGRAM_BOT_TOKEN)` и `Dispatcher()`.
- Регистрация роутеров из `bot/handlers/start.py` и `bot/handlers/query.py` (admin-роутер из фазы 05 подключается позже).
- `async def main()` — `await dp.start_polling(bot)`.
- `if __name__ == "__main__": asyncio.run(main())`.
- Базовое логирование через `logging.basicConfig(level=logging.INFO)`.

### `bot/handlers/start.py`
Router с двумя хендлерами:
- `/start` — приветственное сообщение:
  ```
  Привет! Я MedAP — бот-ассистент для медицинских студентов.

  Просто напиши мне вопрос по теме из учебников — я найду
  ответ строго по материалам и пришлю с указанием источника.

  Доступные команды:
  /help — как пользоваться
  /limit — сколько запросов осталось сегодня
  ```
- `/help` — аналогичная инструкция + примеры трёх режимов (вопрос / "сделай конспект по ..." / "объясни простыми словами ...").

### `bot/handlers/query.py`
Router с одним хендлером на `F.text` (любой текст, не начинающийся с `/`):
1. Отправить `chat.do("typing")` (через `bot.send_chat_action`).
2. `chunks = await retriever.retrieve(message.text)`.
3. `answer = await generator.generate_answer(message.text, chunks)`.
4. `await message.answer(answer)`.
5. Обработка исключений из генератора — `try/except`, при ошибке ответить "Произошла ошибка, попробуй ещё раз через минуту."

### `/limit` (заглушка в этой фазе)
Команда регистрируется в `start.py`, но в этой фазе просто отвечает "Лимиты будут добавлены в следующем обновлении" — полноценная реализация в фазе 04, чтобы не было 404 на команду уже сейчас.

### Тест фазы
1. Убедиться, что `TELEGRAM_BOT_TOKEN` валиден (через `bot.get_me()` при старте — залогировать username бота).
2. Запустить `python -m bot.main` локально.
3. В Telegram: отправить `/start` — проверить текст приветствия.
4. Отправить вопрос по теме из тестового PDF, загруженного в фазе 01 — проверить, что приходит ответ с `[Автор, ...]`.
5. Отправить вопрос с "сделай конспект по ..." — проверить структурированный ответ.
6. Отправить вопрос не по теме материалов — проверить стандартный ответ про отсутствие информации.

## Зависимость для следующих фаз
- Фаза 04 добавляет middleware в `dp` (регистрируется в `bot/main.py`) и реализует `/limit` полноценно.
- Фаза 05 добавляет admin-роутер в `bot/main.py`.

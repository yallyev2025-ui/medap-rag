# Фаза 02 — Генератор ответов (Gemini + главный промпт + режимы)

## Цель
Реализовать `rag/generator.py`, который получает найденные чанки (фаза 01) и вопрос студента, определяет режим ответа (вопрос/конспект/объяснение) и возвращает финальный текст ответа от Gemini 2.0 Flash со ссылкой на источники.

## Предпосылки
Фаза 01 выполнена: `retriever.retrieve()` возвращает список чанков с `content, subject, author, title, distance`.

## Что создать

### `rag/generator.py`

#### Константа `SYSTEM_PROMPT`
Точный текст из ТЗ (на русском), с плейсхолдерами `{context}` и `{question}`:
```
Ты медицинский ассистент MedAP.

АБСОЛЮТНОЕ ПРАВИЛО: отвечай ТОЛЬКО на основе
контекста из учебников ниже. Никаких других
источников. Никогда.

Если ответа нет в контексте — говори:
"Этой информации нет в материалах MedAP.
Попробуй переформулировать вопрос."

ЗАПРЕЩЕНО:
- Использовать знания не из контекста
- Додумывать и дополнять от себя
- Отвечать по памяти
- Говорить "обычно", "как правило", "известно что"

ОБЯЗАТЕЛЬНО:
- Указывай источник: [Автор, учебник]
- Отвечай на русском языке
- Просто и чётко, как студент студенту
- Без воды

{mode_instruction}

Контекст из учебников:
{context}

Вопрос студента: {question}
```

#### Определение режима — `detect_mode(question: str) -> Literal["question", "conspect", "explanation"]`
Ключевые слова (regex, case-insensitive, на русском):
- `conspect`, если вопрос содержит "конспект", "кратко разбери", "структурируй", "выпиши основное"
- `explanation`, если содержит "объясни", "простыми словами", "по-простому", "на пальцах", "аналогия"
- иначе `question` (прямой ответ)

`mode_instruction` для каждого режима — короткая доп. инструкция, вставляемая в промпт:
- `question`: "Дай прямой и точный ответ на вопрос."
- `conspect`: "Сделай структурированный конспект по теме: заголовки, пункты, ключевые определения."
- `explanation`: "Объясни простыми словами, используй аналогии и примеры ТОЛЬКО из контекста ниже."

#### Сборка контекста — `build_context(chunks: list[ChunkResult]) -> str`
Для каждого чанка формат:
```
[Автор, Название учебника]
<текст чанка>
```
Чанки разделяются `\n---\n`.

#### Порог релевантности
- `MAX_DISTANCE_THRESHOLD` (например 0.5 для cosine distance, подбирается экспериментально — задать как константу с TODO-комментарием для калибровки в фазе 06 на реальных данных).
- Если у всех топ-5 чанков `distance > MAX_DISTANCE_THRESHOLD` → не вызывать Gemini, сразу вернуть стандартный ответ "Этой информации нет в материалах MedAP. Попробуй переформулировать вопрос." (экономия запросов к Gemini).

#### Основная функция — `async def generate_answer(question: str, chunks: list[ChunkResult]) -> str`
1. Проверка порога релевантности.
2. `detect_mode(question)`.
3. `build_context(chunks)`.
4. Сборка финального промпта из `SYSTEM_PROMPT`.
5. Вызов `google.generativeai` (модель `settings.GEMINI_MODEL`), `generate_content_async`.
6. Возврат `response.text`.
7. Обработка ошибок API (timeout, rate limit) — пробросить с понятным сообщением, чтобы хендлер в фазе 03 мог показать пользователю "Произошла ошибка, попробуй позже".

### Тест фазы
Скрипт `scripts/test_generator.py` (временный, для ручного теста):
1. Захардкодить 2-3 мок-чанка (текст + author + title), вызвать `generate_answer("Что такое инфаркт миокарда?", mock_chunks)`.
2. Проверить, что ответ на русском, содержит `[Автор, ...]`, не содержит фраз "обычно"/"как правило".
3. Протестировать вопрос с "сделай конспект по ..." → убедиться, что `detect_mode` вернул `conspect` и ответ структурирован.
4. Протестировать вопрос не по теме мок-чанков → убедиться, что возвращается стандартная фраза без вызова Gemini (если distance выше порога) или что Gemini сам её возвращает (если порог не сработал — тоже ок, главное чтобы не было "галлюцинаций").

Требуется `GEMINI_API_KEY` в `.env` для реального вызова — без него тест ограничивается проверкой `detect_mode` и `build_context` (чистые функции, без сети).

# AGENTS.md — бот medap-rag

Постоянные правила и память проекта ведутся в репозитории сайта: `/workspaces/Medapsite` (`AGENTS.md`, `docs/ai/STATE.md`, `DECISIONS.md`, `REPOS.md`). Читать их оттуда; здесь не дублируются. Правила бота — `CLAUDE.md` (подключён через `opencode.json`). Команды `/continue`, `/save`, `/check` — в сайте; `/review` и субагент `reviewer` есть и здесь.

Коротко (подробности — в `AGENTS.md` сайта):
- Роли: владелец отвечает за продукт, я за техническую часть. По-русски, простыми словами. Новые нетривиальные функции — сначала вопросы и согласование, потом план и код.
- Ветка бота и боевого деплоя: `claude/document-timeweb-migration-z75kve`. Новых веток без поручения не создавать. Коммиты бота — отдельно от коммитов сайта.
- **Push — только после явного «да» владельца** (push = боевой деплой на Timeweb). Показать коммиты перед запросом. Без force push, `reset --hard`, `--no-verify`; Git-конфиг не менять; токены в адреса не вписывать.
- Безопасность: без разрешения не трогать боевую БД, секреты, деплой; секреты не выводить.
- Проверки: `python3 scripts/test_<затронутое>.py`, `py_compile`; Docker-образ собирается только на Timeweb.
- Не ломать работающее: Telegram-бот MedAP, `slides_bot/`, API для сайта.
- Модели агентов и `default_agent` — в `opencode.json` (как в сайте): Plan/Reviewer/Explore — GLM 5.3 Flash, Build — DeepSeek V4.1 Flash.
- Дизайн презентаций — отдельная система, не путать с дизайном сайта: `docs/DESIGN-PRESENTATIONS.md`.

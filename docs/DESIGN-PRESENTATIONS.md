# Дизайн презентаций бота (medap-rag) — отдельно от сайта

Визуальный стиль презентаций **не смешивать** с дизайн-системой сайта (`/workspaces/Medapsite/docs/ai/DESIGN.md`). Это отдельная система; здесь только указатели, значения не выдумывать.

## Источники

- `slides-engine/fonts/` — шрифты движка: Caveat, Manrope, Source Serif 4 (файлы + лицензии OFL).
- `slides-engine/render-drafts.mjs`, `slides-engine/package.json` — рендер черновиков (использует `fontkit`).
- `slides_bot/assets/` — вложения бота презентаций.
- Общая система колод описана в репозитории сайта: `packages/slides/` (`design-tokens.test.ts`, `palette-audit.ts`, `fonts.ts`, `styles.ts` и др.).

## Правило

Перед любой правкой внешнего вида презентаций — сначала уточнить, какой источник используется в конкретном потоке (движок бота или пакет слайдов сайта), затем менять только его. Не переносить цвета и шрифты сайта в презентации и наоборот без согласования владельца.

Актуальные значения снимать из кода (`slides-engine/fonts`, `packages/slides`), а не из этого файла.

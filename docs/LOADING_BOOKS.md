# Как грузить учебники и клинические рекомендации, не мешая боту (28.10.2026)

Бот и загрузка делят один сервер — поэтому крупные загрузки лучше делать **на отдельной машине**, которая пишет в ту же базу.

## Что нужно на отдельной машине
- Python 3.12 и зависимости бота: `pip install -r requirements.txt` (для сканов ещё `tesseract-ocr`, `tesseract-ocr-rus`, `poppler-utils`; проще — собрать тот же Docker-образ и запускать команды внутри него).
- Переменные: `DATABASE_URL` — **та же база, что у бота** (в панели Timeweb для базы данных включить доступ из интернета и разрешить адрес вашей машины; пароль не выкладывать никуда), `EMBEDDING_MODEL_NAME` — такая же, как у бота (иначе поиск перестанет находить загруженное). Ключи S3 — если хранятся оригиналы; без них загрузка работает, но оригинал не сохраняется.
- Мощность: чем больше ядер и память, тем быстрее; с видеокартой эмбеддинги считаются в разы быстрее и подхватываются сами. Подойдёт арендованный на день сервер на 16+ ядер и 16 ГБ.

## Учебники
Положите файлы так: `учебники/<предмет>/<Автор> - <Название>.pdf` (PDF с текстом, сканы, `.docx`, `.txt`), затем:
```
python -m scripts.load_textbooks учебники --dry-run   # сначала посмотреть список
python -m scripts.load_textbooks учебники              # загрузка
```
Загруженное с тем же названием и предметом пропускается, поэтому скрипт можно прерывать и запускать снова. Ошибка одной книги не останавливает остальные.

## Клинические рекомендации (~800) — с планшета, без ноутбука
Самый простой путь — **Google Colab** (бесплатная видеокарта, работает в браузере планшета): блокнот `notebooks/load_clinreks_colab.ipynb`.
1. Откройте блокнот в Colab (загрузите файл на colab.research.google.com), выберите видеокарту T4 (Среда выполнения → Сменить среду выполнения).
2. Заархивируйте папку `клинреки` (на планшете: «Файлы» → долгое нажатие → «Сжать») и положите архив в корень Google Диска.
3. В ячейке «НАСТРОЙКИ» вставьте внешний адрес базы Timeweb. В панели Timeweb включите доступ к базе из интернета на время загрузки и после неё выключите (адрес Colab меняется, поэтому ограничить по IP нельзя; пароль базы никому не показывайте и не публикуйте блокнот с ним).
4. «Среда выполнения → Выполнить все». Блокнот возобновляемый: если остановится, запустите снова — загруженное пропустит.
Загрузка идёт на видеокарте в Colab, боевой сервер в это время почти не нагружается (только записи в базу).
Если нужен план Б без Colab: арендованный сервер на день и SSH-приложение на планшете (Termius) — команды ниже.

### Специальности и возраст
Раскладка: `клинреки/<возраст>/<специальность>/<файл>.pdf`, например `взрослые/кардиология/…`, `дети/педиатрия/…`. Папка возраста — `subject` (по ней бот уже ищет), вложенная папка — специальность (`topic`), она записывается в базу. Фильтр «по специальности» в меню бота пока **не сделан**: данные в базе будут размечены заранее, добавить кнопку можно отдельным шагом.
Положите PDF по папкам категорий: `клинреки/взрослые`, `клинреки/дети`, `клинреки/взрослые_и_дети` и запустите:
```
python -m scripts.load_clinreks клинреки --workers 4 --batch-size 64
```
Скрипт возобновляемый (по имени файла), пишет ошибки в `errors.log`. Не запускайте его на боевом сервере, пока им пользуются люди; нужен именно отдельный компьютер. Время зависит от объёма и машины: на процессоре без видеокарты это часы, с видеокартой заметно меньше (точной цифры у меня нет — запустите на 10 файлах и умножьте).

## После загрузки
Бот сам увидит новые книги (поиск идёт по базе). Если включён кеш ответов, очистите его, чтобы старые ответы не закрывали новые источники.

## Если грузите прямо на боевом сервере (не рекомендуется)
Включён щадящий режим: `INGEST_THREADS=4`, `INGEST_PAUSE_S=0.4`, `OCR_WORKERS=2`. Грузите ночью, по одной книге.

## Большой реранкер не лежит в образе и не грузится (28.10.2026)
Теперь по умолчанию `RERANKER_BACKEND=onnx`, `RERANKER_TORCH_FALLBACK=false`. При сборке образа большая модель скачивается только для сжатия и удаляется тем же шагом (`scripts/build_reranker.sh`), в образе остаётся сжатая (~0,6 ГБ). Порог для сжатой модели подбирается автоматически при сборке (`scripts/calibrate_onnx_threshold.py` → `threshold.json` рядом с моделью): решения сжатой модели сверяются с большой на 88 парах «вопрос — фрагмент»; порог никогда не выше общего. Переменные `RERANK_SCORE_THRESHOLD_ONNX` и `RERANKER_BACKEND=torch` по-прежнему главнее (откат). Оставить большую модель в образе — аргумент сборки `KEEP_TORCH_RERANKER=1`. Если сжатая модель не собралась, сборка падает (образ без реранкера не нужен).
⚠️ Это не проверено на настоящей сборке (у меня нет доступа к torch и Hugging Face). После первой сборки проверьте в журнале сборки строки «Порог для сжатого реранкера…» и «Большая модель реранкера удалена…», а в журнале запуска — `reranker=onnx`, затем `python -m scripts.compare_rerankers` на реальных вопросах и спросите бота пару вопросов, которых нет в учебниках (должен отказать) и пару обычных.

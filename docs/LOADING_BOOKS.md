# Как грузить учебники и клинические рекомендации, не мешая боту (28.10.2026)

Бот и загрузка делят один сервер — поэтому крупные загрузки лучше делать **на отдельной машине**, которая пишет в ту же базу.

## Что нужно на отдельной машине
- Python 3.12 и зависимости бота: `pip install -r requirements.txt` (для сканов ещё `tesseract-ocr`, `tesseract-ocr-rus`, `poppler-utils`; проще — собрать тот же Docker-образ и запускать команды внутри него).
- Переменные: `DATABASE_URL` — **та же база, что у бота** (в панели Timeweb для базы данных включить доступ из интернета и разрешить адрес вашей машины; пароль не выкладывать никуда), `EMBEDDING_MODEL_NAME` — такая же, как у бота (иначе поиск перестанет находить загруженное). Ключи S3 — если хранятся оригиналы; без них загрузка работает, но оригинал не сохраняется.
- Мощность: чем больше ядер и память, тем быстрее; с видеокартой эмбеддинги считаются в разы быстрее и подхватываются сами. Подойдёт арендованный на день сервер на 16+ ядер и 16 ГБ.

## Учебники
Положите файлы так: `учебники/<предмет>/<Автор> - <Название>.pdf` (PDF с текстом, сканы, `.docx`, `.txt`), затем:
```
python -m scripts.load_textbooks учебники --dry-run   # сначала посмотреть список
python -m scripts.load_textbooks учебники              # загрузка
```
Загруженное с тем же названием и предметом пропускается, поэтому скрипт можно прерывать и запускать снова. Ошибка одной книги не останавливает остальные.

## Клинические рекомендации (~800)
Положите PDF по папкам категорий: `клинреки/взрослые`, `клинреки/дети`, `клинреки/взрослые_и_дети` и запустите:
```
python -m scripts.load_clinreks клинреки --workers 4 --batch-size 64
```
Скрипт возобновляемый (по имени файла), пишет ошибки в `errors.log`. Не запускайте его на боевом сервере, пока им пользуются люди; нужен именно отдельный компьютер. Время зависит от объёма и машины: на процессоре без видеокарты это часы, с видеокартой заметно меньше (точной цифры у меня нет — запустите на 10 файлах и умножьте).

## После загрузки
Бот сам увидит новые книги (поиск идёт по базе). Если включён кеш ответов, очистите его, чтобы старые ответы не закрывали новые источники.

## Если грузите прямо на боевом сервере (не рекомендуется)
Включён щадящий режим: `INGEST_THREADS=4`, `INGEST_PAUSE_S=0.4`, `OCR_WORKERS=2`. Грузите ночью, по одной книге.

## Большая модель реранкера не нужна в памяти
`RERANKER_BACKEND=onnx`, `RERANK_SCORE_THRESHOLD_ONNX=<порог из compare_rerankers>`, `RERANKER_TORCH_FALLBACK=false` — тогда torch-версия (≈2,3 ГБ) в память не загружается вообще. Если сжатая модель не найдётся, бот ответит ошибкой, а не молча загрузит большую.
